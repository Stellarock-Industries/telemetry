Put the game's telemetry .proto files here (keeping the folder layout), e.g.
  schema/sc/game/telemetry/v1/api.proto
  schema/sc/game/telemetry/v1/types.proto
Or just click "Download schema" in the app's Setup tab, which saves them into the app's own schema folder.
The app uses the folder in your user-data directory first (Setup -> "Open schema folder").
